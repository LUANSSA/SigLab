# 🧪 SiGLab - Sistema de Gestão de Laboratórios

🚀 Sistema de gestão de laboratórios (SigLab), desenvolvido com FastAPI, para controle de equipamentos, registro de manutenções e gerenciamento de reservas em ambientes técnicos.

---

## 🛠️ Tecnologias

* 🐍 Python
* ⚡ FastAPI
* 🗄️ MySQL
* Uvicorn
* Git e GitHub

---

## 📋 Pré-requisitos

Antes de executar o projeto, é necessário possuir instalado:

* Python 3.12 ou superior
* MySQL 8 ou superior
* Git
* Ambiente virtual Python (venv)
* FastAPI
* Uvicorn
* MySQL Connector/Python

Clonando o repositório:
```bash
git clone https://github.com/LUANSSA/SigLab
cd SigLab
```
Criar e ativar o ambiente virtual no linux:
```bash
python3 -m venv venv
source venv/bin/activate
```
Criar e ativar o ambiente virtual no windows:
```bash
python -m venv venv
venv\Scripts\activate
```

Comandos de instalação:
```bash
pip install fastapi
pip install uvicorn
pip install mysql-connector-python
```

---

## ▶️ Como rodar

```bash
uvicorn app.main:app --reload
```
